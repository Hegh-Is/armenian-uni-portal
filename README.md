# Armenian Higher Education Unified Portal & Trust-First Academic Ecosystem
**ՀՀ համալսարանների միասնական թվային ուղեցույց-պորտալ**

Առաջին տարբերակի տեխնիկական առաջադրանքի (ՏԱ v1.0) հիման վրա նախագծվող եռալեզու (**HY / EN / RU**) թվային հարթակ՝ Հայաստանի Հանրապետության բուհերի, կրթական ծրագրերի, միջազգային շարժունության հնարավորությունների և ակադեմիական թափուր հաստիքների միասնական, ստուգելի տվյալների ու համեմատական վերլուծության համար։

## Խնդիրը և լուծումը
ՀՀ բուհերի տվյալները ցրված են տարբեր ինքնավար կայքերում ու ֆորմատներում, ինչը բարդացնում է ծրագրերի, վարձավճարների ու ընդունելության պահանջների համեմատությունը և թափուր ակադեմիական հաստիքների որոնումը։ Հարթակը միավորում է այդ ամենը մեկ ստանդարտացված համակարգում՝ շեշտադրելով **ստուգելի փաստերը**, **AI որոնումն ու ուղղորդումը** և **համեմատական գործիքները**։

## Հիմնական հնարավորություններ
* **Trust Lens («Ապացույցի ոսպնյակ»)** — յուրաքանչյուր փաստի (վարձավճար, վերջնաժամկետ, ընդունելության պայման) կցված է պաշտոնական աղբյուրի հղումը, էջի վերնագիրը, բնօրինակ հատվածը և ստուգման ամսաթիվը․ բացակայող տվյալները չեն հորինվում։
* **Smart Search & RAG Assistant** — բնական լեզվով որոնում (HY/EN/RU) և վեկտորային որոնման ու RAG-ի վրա հիմնված AI ասիստենտ՝ հիմնված բացառապես պաշտոնական աղբյուրների վրա։
* **Comparison Engine & Fit Score** — միաժամանակ մինչև 4 ծրագրի կողք-կողքի համեմատություն և անձնային համապատասխանության գնահատում՝ ըստ բյուջեի, մասնագիտության, լեզվի, քաղաքի, ՄՈԳ-ի և լեզվական մակարդակի։
* **Change Detection («Ի՞նչ է փոխվել»)** — պաշտոնական էջերի փոփոխությունների ավտոմատ հայտնաբերում և ծանուցում պահպանված ծրագրերի համար։
* **Universities, Mobility & Academic Career Board** — ՀՀ բուհերի և ծրագրերի կատալոգ, փոխանակման ծրագրեր (Erasmus+, DAAD, IREX և այլն), ուսանողական իրադարձություններ և դասախոսական/գիտական թափուր հաստիքների միասնական հարթակ։
* **Personal Dashboard** — դերային գրանցում (Դիմորդ/Ուսանող, Միջազգային ուսանող, Ծնող/Խորհրդատու, Դասախոս/Աշխատակից), պահպանված ցանկեր, վերջնաժամկետների օրացույց և ծանուցումների կառավարում։

## Ճարտարապետություն և տեխնոլոգիական կույտ (Tech Stack)
* **Frontend:** Next.js (React), TypeScript, Tailwind CSS (SSR, i18n HY/EN/RU, Mobile-first)
* **Backend:** Python (FastAPI), RESTful API, JWT/OAuth2
* **Database:** PostgreSQL + `pgvector`
* **Crawler & Validation:** Python (Playwright / Scrapy / BeautifulSoup, content hashing), Pydantic կանոնների շարժիչ
* **AI & RAG:** LLM (Gemini Flash / GPT-4.1 mini փոխարինելի մոդելներ), Gemini Embeddings + Vector Search

## Իրականացման փուլեր (Roadmap)
1. **Փուլ 1 — MVP (1–3-րդ ամիսներ):** PostgreSQL սխեմա, տվյալների հավաքագրում/crawl, 5 հիմնական էջերի բազային ֆունկցիոնալություն, ֆիլտրեր, մինչև 4 ծրագրի համեմատություն և Trust Lens։
2. **Փուլ 2 — AI և անհատականացում (4–5-րդ ամիսներ):** Եռալեզու RAG AI ասիստենտ, բնական լեզվով որոնում, Fit Score, «Ի՞նչ է փոխվել» ծանուցումներ և անձնական օրացույց։
3. **Փուլ 3 — Էկոհամակարգի ընդլայնում (6-րդ ամսից հետո):** Շարժունության ու կրթաթոշակային ծրագրերի ընդլայնում և բուհերի ադմինիստրատորների ինքնասպասարկման վահանակ։

## Կարգավիճակ
